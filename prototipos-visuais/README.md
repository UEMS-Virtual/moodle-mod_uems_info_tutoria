# Protótipos visuais — mod_uems_info_tutoria

Protótipos descartáveis para avaliar o visual do módulo no Moodle.

Protótipos atuais:

- `variante-a-quadros-simples.html` — lista completa para professores, coordenação e demais papéis.
- `variante-e-painel-contatos.html` — visual padrão do estudante, mostrando apenas o próprio polo.
- `variante-g-aluno-alterna-visualizacao.html` — experimento: estudante começa na visão do próprio polo e pode alternar para lista completa com JavaScript.

Decisão visual atual:

- A e E são as referências principais.
- G testa a ideia de alternância sem salto brusco de layout.

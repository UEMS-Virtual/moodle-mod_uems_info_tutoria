# mod_uemsinfotutoria

Plugin Moodle para exibir a equipe de tutoria e mediação pedagógica de uma disciplina.

## Norte do projeto

A documentação principal está em:

- `docs/NORTE_DO_PROJETO.html`

## Protótipos escolhidos

- Estudantes: `prototipos-visuais/variante-e-painel-contatos.html`
- Estudantes com alternância: `prototipos-visuais/variante-g-aluno-alterna-visualizacao.html`
- Demais papéis: `prototipos-visuais/variante-a-quadros-simples.html`

## Resumo

- Tutor Presencial: papel `mod_tutor`.
- Mediador Pedagógico: papel `mod_medpdg`.
- Polo: grupo cujo nome contém `polo`.
- Estudante abre vendo seu próprio polo.
- Estudante pode alternar para a lista completa.
- Demais papéis veem a lista completa da sala.
- Nomes dos tutores/mediadores abrem conversa no Moodle.
- Cores devem seguir variáveis do tema Moodle ativo.
- O plugin não cadastra tutores nem polos.
